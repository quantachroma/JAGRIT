2. Executive Summary & Problem Context

Communities across Jharkhand face chronic, localized challenges spanning drinking water contamination (arsenic, fluoride, iron), agricultural post-harvest decay, artisanal livelihood bottlenecks (lac, tussar silk, minor forest produce), and public sanitation. While citizens are the first to detect these breakdowns, no structured, accessible mechanism exists to capture and channel these challenges for systematic engineering and scientific resolution.

Higher Education Institutions (HEIs) possess research laboratories, academic faculty, and a large student population. However, academic research remains largely disconnected from grassroots community needs due to fragmented institutional collaboration.

JAGRIT System Mission
A closed-loop platform that crowdsources societal problems via low-barrier channels (Mobile App, Web, and WhatsApp Voice Bot in Hindi and Santhali), uses AI for deduplication and triage, and routes validated challenges to verified universities. Multi-university acceptance triggers a dynamic 3-stage hackathon backed by tranche-based escrow funding (Government + CSR). Validated solutions award NEP 2020 credits and are verified via a 45-day citizen feedback quorum.

5. End-to-End User Journeys (Step-by-Step)

5.1 Citizen Ingestion via WhatsApp (Multilingual Voice)

  1. Citizen sends a voice note or image to the JAGRIT WhatsApp Cloud API endpoint.
  2. Conversational agent auto-detects language preference (Hindi, Santhali, English).
  3. Inbound audio binary is forwarded to the fine-tuned Whisper-large-v3 / Bhashini ASR pipeline.
  4. Citizen is prompted via WhatsApp message to share their live GPS location pin.
  5. System performs a 500m spatial buffer query against existing tickets.
  6. If unique: Generates Ticket #JAG-YYYY-DIST-XXXX with an SMS/WhatsApp tracking URL.
  7. If duplicate (≥85% semantic similarity within 500m): Automatically merges media, increments upvotes by 1, and notifies the citizen.

5.2 Evaluator Audit & University Allocation

  1. Submission enters the Evaluator Triage Queue with an AI confidence ring.
  2. If Civic Routine: Dispatched via webhook to ULB/JharSewa; ticket closed on JAGRIT.
  3. If Applied R&D: Evaluator authorizes the state innovation grant ceiling (e.g., ₹3,50,000) and opens corporate CSR co-sponsorship.
  4. Matching engine broadcasts the challenge to qualified institutions based on lab facilities, patents, and faculty specializations.
  5. A 10-day bidding window countdown begins.

5.3 University Bidding & Dynamic Hackathon Mode

  1. Solo Acceptance: Exactly 1 HEI accepts → Routes to Direct R&D Track. Work Breakdown Structure locked; Tranche 1 (30%) disbursed.
  2. Multi-HEI Acceptance: ≥2 HEIs accept → Routes to Dynamic Hackathon Track:
    • Round 1 (Ideation): 5-slide pitch deck (PDF) and video approach summary within 14 days. Top 3–5 teams shortlisted.
    • Round 2 (Mentoring & Prototype): Industry Mentor review sprints and bench-scale test data upload. Top 2 teams advance.
    • Round 3 (DPR & Physical Defense): Comprehensive Detailed Project Report (DPR) with Bill of Materials (BOM). Physical presentation at Ranchi DHTE headquarters.
  3. Jury scores submissions: Feasibility (40%), Sustainability (30%), and Cost (30%). Winning team receives deployment rights and unlocks Tranche 1 funding.

6. Comprehensive Functional Requirements

Module 1: Ingestion Engine
FR-1.1: WhatsApp Conversational Webhook (Hindi/Santhali ASR, GPS pin parsing).
FR-1.2: Web/Mobile Studio with client-side image compression (≤500 KB) and video uploads (≤30s).
FR-1.3: Institutional Problem Dossier mode for BDOs/PRIs to upload historical test logs (CSV/PDF).
Module 2: AI Ingestion & Deduplication
FR-2.1: Fine-tuned Whisper-large-v3 model with ≤14% Word Error Rate (WER) on Santhali and Hindi.
FR-2.2: Computer Vision laser sweep displaying bounding boxes over structural and water defects.
FR-2.3: PostGIS 500m spatial buffer query + text-embedding-3-large cosine similarity (≥0.85 threshold).
FR-2.4: Zero-shot DeBERTa-v3 classifier separating Type A (Routine Civic) from Type B (Applied Innovation R&D).
Module 3: Bidding & Dynamic Hackathon Engine
FR-3.1: Explainable AI (XAI) compatibility scorecards (5-axis spider chart).
FR-3.2: 10-day bidding window with dynamic switching: Solo HEI (Direct R&D) vs. ≥2 HEIs (Dynamic Hackathon).
FR-3.3: Consortia support enabling inter-university multidisciplinary proposals (e.g., BIT Mesra + BAU).
Module 4: Milestone Escrow & Governance
FR-4.1: Tranche-based escrow disbursement: Tranche 1 (30% on proposal), Tranche 2 (40% on bench validation + NABL certificate), Tranche 3 (30% on field deployment + PESA Gram Sabha NOC).
FR-4.2: Automated SLA breach monitors: Warning on Day +7, Dean escalation on Day +14, Default and fund clawback on Day +30.
FR-4.3: Mandatory O&M Handover: Training of 2 local VLEs/Jal Sahiyas with illustrated vernacular SOP and 12-month spares escrow.
Module 5: NEP 2020 Academic Credits & Feedback Quorum
FR-5.1: Digital transfer of 2–4 credits to APAAR / Academic Bank of Credits (ABC) based on verified work hours (30 hrs = 1 Credit).
FR-5.2: 45-day unassisted operational maturation buffer before validation opens.
FR-5.3: AI Population-Weighted Quorum calculation: Quorum_min = max(15, Ceil(k * sqrt(N))).
FR-5.4: NLP classification separating Critical Defects (triggers 45-day repair sprint) from Cosmetic Grievances (ticket marked Solved).

9. Operational Governance & Legal Frameworks

9.1 NEP 2020 Academic Credits & APAAR Engine

Standardized at 30 verified student workhours = 1 Academic Credit under UGC / NCrF norms. Upon project sign-off, encrypted JSON payloads transfer credits directly into students' APAAR / DigiLocker transcripts under Community Engagement (2 Credits) or Major Capstone Project (4 Credits).

9.2 Tripartite IPR Concordat

  • Students & Faculty: Retain exclusive moral rights as Inventors and hold ≥60% equity in commercial spin-off startups.
  • University: Holds patent custody and receives a 20–30% royalty share on commercial licensing.
  • Industry CSR Co-Sponsor: Receives Right of First Refusal (ROFR) for manufacturing rights and a perpetual internal royalty-free license.
  • Government of Jharkhand: Retains an irrevocable, royalty-free license for public deployments statewide.

9.3 Tribal Governance (PESA Act 1996 Compliance)

Deployments in Fifth Schedule areas require the local Panchayat Secretary (Sachiv) to upload an authenticated Gram Sabha Resolution / NOC prior to hardware installation, preventing regulatory or cultural conflict.

10. Complete Database Schema (PostgreSQL + PostGIS DDL)

CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS "postgis";
CREATE EXTENSION IF NOT EXISTS "vector";

-- 1. Users Master Table
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    phone VARCHAR(15) UNIQUE,
    email VARCHAR(255) UNIQUE,
    full_name VARCHAR(150) NOT NULL,
    role VARCHAR(35) CHECK (role IN ('CITIZEN', 'PRI_OFFICER', 'STUDENT', 'FACULTY_PI', 'INDUSTRY_MENTOR', 'EVALUATOR', 'ADMIN')),
    apaar_id VARCHAR(20) UNIQUE,
    institution_id UUID,
    preferred_language VARCHAR(10) DEFAULT 'hi',
    is_phone_verified BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Master Challenge Ticket
CREATE TABLE challenges (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    ticket_number VARCHAR(50) UNIQUE NOT NULL,
    submitted_by UUID REFERENCES users(id),
    submission_channel VARCHAR(25) CHECK (submission_channel IN ('APP', 'WEB', 'WHATSAPP', 'INSTITUTIONAL_DOSSIER')),
    title VARCHAR(255) NOT NULL,
    description TEXT NOT NULL,
    description_embedding vector(1536),
    raw_audio_url TEXT,
    media_urls TEXT[],
    location GEOMETRY(Point, 4326) NOT NULL,
    district VARCHAR(100) NOT NULL,
    block VARCHAR(100),
    panchayat VARCHAR(100),
    upvotes_count INT DEFAULT 1,
    status VARCHAR(50) DEFAULT 'PENDING_HITL',
    category_type VARCHAR(30),
    matched_domains TEXT[],
    allocated_pool_inr NUMERIC(12, 2) DEFAULT 0.00,
    bidding_deadline TIMESTAMP WITH TIME ZONE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_challenges_spatial ON challenges USING GIST(location);

-- 3. Projects Execution & Escrow Ledger
CREATE TABLE projects (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    challenge_id UUID REFERENCES challenges(id) ON DELETE CASCADE,
    execution_mode VARCHAR(25) CHECK (execution_mode IN ('DIRECT_RND', 'DYNAMIC_HACKATHON', 'CONSORTIUM')),
    lead_university_id UUID NOT NULL,
    partner_university_id UUID,
    pi_faculty_id UUID REFERENCES users(id),
    student_team_ids UUID[],
    industry_mentor_id UUID REFERENCES users(id),
    current_hackathon_round INT DEFAULT 1,
    total_budget_inr NUMERIC(12, 2) NOT NULL,
    tranche_1_disbursed BOOLEAN DEFAULT FALSE,
    tranche_2_disbursed BOOLEAN DEFAULT FALSE,
    tranche_3_disbursed BOOLEAN DEFAULT FALSE,
    pesa_noc_url TEXT,
    field_deployment_date TIMESTAMP WITH TIME ZONE,
    maturation_ends_at TIMESTAMP WITH TIME ZONE,
    resolution_status VARCHAR(35) DEFAULT 'IN_PROGRESS',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 4. 45-Day Feedback & Quorum Log
CREATE TABLE feedback_ledger (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id UUID REFERENCES projects(id) ON DELETE CASCADE,
    citizen_id UUID REFERENCES users(id),
    voter_location GEOMETRY(Point, 4326) NOT NULL,
    is_core_functional_pass BOOLEAN NOT NULL,
    complaint_type VARCHAR(30) CHECK (complaint_type IN ('NONE', 'COSMETIC_GRIEVANCE', 'CRITICAL_DEFECT')),
    raw_voice_url TEXT,
    transcribed_feedback TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX idx_feedback_spatial ON feedback_ledger USING GIST(voter_location);

-- 5. R&D Failure Repository
CREATE TABLE rnd_failure_repository (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    project_id UUID REFERENCES projects(id),
    failure_classification VARCHAR(25) CHECK (failure_classification IN ('MINOR_FAILURE', 'MAJOR_FAILURE')),
    root_cause_analysis TEXT NOT NULL,
    attempted_solution_summary TEXT NOT NULL,
    lessons_learned TEXT NOT NULL,
    escalated_to_national_hackathon BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

  • Dynamic Hackathon Trigger: Automatically opens Round 1 ideation workspaces when ≥2 universities accept the same ticket.
  • Explainable AI Visualization: Displays a 5-axis spider chart breaking down institutional compatibility scores.
  • Escrow Milestone Gates: Tranches 1, 2, and 3 disburse sequentially only upon verified milestone documentation uploads.
  • NEP 2020 Credit Deposits: Successfully produces APAAR/ABC-formatted credit payloads based on verified workhours.
  • AI Quorum & NLP Filtering: Enforces population-weighted voting quorums and separates critical defects from cosmetic grievances.
  • R&D Failure Indexing: Successfully generates post-mortem entries in the Failure Repository upon project failure sign-off.
